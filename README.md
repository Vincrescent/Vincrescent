> **An anime-inspired tower defense game built from the ground up on Roblox.**

### Key Highlights & Systems Built:
- 🔮 **Summoning & Gacha System**: Multi-tier unit summoning with dynamic pity rates, custom animations, and rarity rolls.
- ⚔️ **Trait & Synergy Engine**: Complex stat mutations, element matchups, and aura buffs calculated dynamically.
- 📈 **Layered Progression**: Unit leveling, evolutions, limit-breaking, and stage progression.
- ⚡ **Optimized Wave Spawning**: Efficient client-side replication and server validation for smooth combat against large unit counts.
